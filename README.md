# LUNÉRA — لونيرا

متجر عربي بهوية الأزرق الملكي #071A3D، والبيج الشامبانيا #F6D7BA، والذهبي #C7A45D.

## تنظيم الملفات
- assets/: صور الواجهة والأقسام والخلفية والصور المرجعية.
- beauty/: صور منتجات الجمال والعناية.
- accessories/: صور منتجات الإكسسوارات.
- bags/ و school-supplies/: مجلدات جاهزة لإضافة صور الأقسام.
- products.json: بيانات المنتجات الحالية.

## ملفات المتجر
- index.html: واجهة المتجر.
- style.css: التصميم والألوان.
- store.js: وظائف السلة والطلبات.
- admin.html: إدارة المنتجات.
- design-editor.html: محرر التصميم.

التغييرات موجودة في فرع lunera-final-polish-2026-11-04 للمعاينة فقط، ولم تُنشر إلى main أو الموقع الحي.
